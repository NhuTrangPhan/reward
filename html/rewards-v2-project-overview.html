Cách tính % & trạng thái (để đảm bảo khách quan):
  • Phase 1 đối chiếu tài liệu tính năng đã release (CNV_Reward_V2_Tinh_nang_san_pham.pdf) + báo cáo tuần: GotIt LIVE ~95% (e-voucher W22 · quà vật lý W25–26), UrBox ~90% kỹ thuật (29/32 task) — còn đàm phán API UrBox 0/6 (phụ thuộc vendor).
  • Phase 2 theo WBS Reward Network: thiết kế + WBS 79 task 100%, code nghiệp vụ (33 task dev) 0% — dev khởi động W28. % hiển thị là % code, phần thiết kế đã hoàn tất được ghi chú riêng.
  • Phase 3 theo CRM API Coverage Report (32/70 endpoint ~46%) + báo cáo W27 (masking/bảo mật đã xong). Bao gồm cả hardening Phase 1.5 (phần lớn chưa bắt đầu) nên % thấp hơn phần CRM lõi.
Est PD (person-day): ước lượng công mỗi task theo độ phức tạp (đơn giản ~1 PD, trung bình ~2 PD, phức tạp ~3–4 PD), tham chiếu ước lượng gốc của team (Phase 1 MVP ~31,5 PD/15 task; WBS Reward Network ~90 PD/33 task Phase 1). % tiến độ toàn dự án được tính trọng số theo PD, không phải trung bình cộng đơn thuần.
⚠️ Lưu ý khách quan: % là ước lượng dựa trên tài liệu & báo cáo (source code Java không truy cập trực tiếp trong phiên này). Nên đọc kèm cột trạng thái & ghi chú, và hiệu chỉnh khi có số liệu commit/coverage mới.

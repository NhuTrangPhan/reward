⚠️ Vì sao code 85% mà chỉ tính ~17%?

Theo phương pháp đánh giá đã thống nhất: code xong nhưng chưa qua review + test độc lập chỉ tính 20% hoàn thành — 1 tuần để code nhưng ~3 tuần để review + sửa đúng hướng + test, và review có thể phát sinh việc mới. 85% × 20% ≈ 17% hoàn thành thực.

  • Report chống quà rác (P1-18/19) — chưa động
  • Admin config ngành/pool (P1-15/16)
  • QA staging + review độc lập (đang là nút thắt)
